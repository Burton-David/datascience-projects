# Data Science Portfolio

This repository contains projects completed during Flatiron School's 10-month Data Science bootcamp in 2019. The work has been recently updated to use current library versions and improved coding practices.

## Projects

### Credit Card Fraud Detection
Binary classification project using ensemble methods and traditional ML algorithms to detect fraudulent transactions. Includes exploratory data analysis, feature engineering, and model comparison across multiple algorithms including XGBoost and Random Forest.

### Kickstarter Outcome Prediction
Predictive modeling to forecast Kickstarter campaign success based on historical campaign data. Features data cleaning, feature selection, and classification techniques.

### Real Estate Price Prediction
Linear regression analysis to predict housing prices. Demonstrates feature engineering and statistical modeling fundamentals.

### Student Outcome Prediction
Classification project to predict student academic outcomes using demographic and behavioral features.

## Technologies
Python, scikit-learn, pandas, numpy, matplotlib, seaborn, XGBoost
