# Student Outcome Prediction (2019)

Classification project predicting student academic performance based on demographic and behavioral factors.

## What This Was

Applied classification techniques to identify students at risk of poor academic outcomes. Used features like:
- Demographic information
- Attendance patterns
- Prior academic performance
- Socioeconomic indicators

## Why This Mattered

This was my first project dealing with sensitive data where model mistakes have real consequences. Made me think about:
- Fairness and bias in predictive models
- The ethics of using demographic data
- What happens when you optimize for the wrong metric
- How interpretability matters more than raw accuracy in some domains

## Files

`student-outcome-prediction.ipynb`

## Reflection

Looking back, I focused too much on model performance and not enough on:
- Feature importance analysis (which factors actually drive outcomes?)
- Fairness metrics across demographic groups
- Whether predictions would actually help students or just label them
- What interventions could follow from predictions

This project made me realize data science isn't just about accuracy scores.
