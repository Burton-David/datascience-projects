# Student Outcome Prediction

Classification project to predict student academic outcomes.

## Overview
This project builds a predictive model to forecast student academic performance using demographic and behavioral data. The analysis applies classification techniques to identify students at risk and understand key factors influencing academic success.

## Approach
1. Data preprocessing and cleaning
2. Exploratory data analysis
3. Feature engineering
4. Classification modeling
5. Model evaluation and interpretation
